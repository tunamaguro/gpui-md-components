# メールアプリの見本

`md3-components` の再公開だけを使い、画面幅に応じたナビゲーション、一覧と詳細、テーマ切り替え、操作の取り消しを組み合わせるデスクトップ用の見本です。

```sh
cargo run -p mail-sample
```

送信者・件名・本文での検索と、メールの作成・返信を試せます。本文の入力は 1 行です。一覧のスターは詳細メニューから切り替えます。詳細は `docs/agents/backlog.md` を参照してください。

長い本文のメールを送って開くと詳細はスクロールでき、Tab / Shift+Tab で操作部品に移ると表示位置が追従します。一覧と詳細の切り替えやアーカイブ・削除の後もキーボード操作を続けられます。
