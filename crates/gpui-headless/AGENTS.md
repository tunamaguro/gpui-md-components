# gpui-headless

## 役割

特定のデザインシステムに依存しない、見た目を持たない UI の操作基盤。
入力、状態遷移、フォーカス管理、アクセシビリティ情報を担う

## crate 固有の規約

- `gpui` 以外に依存を持たない
- 色・寸法・書体などの見た目や MD3 固有のトークンを持たない。操作に必要な見た目由来の値は呼び出し側から受け取る
- 操作可能な要素には安定した ID を持たせる
- 操作の状態と、支援技術に伝える役割・状態・アクションを一致させる。描画側で操作状態を別に持つことを要求しない
- アクセシビリティ要件の判断には [a11y スキル](../../.agents/skills/a11y/SKILL.md) の一次資料を使う
