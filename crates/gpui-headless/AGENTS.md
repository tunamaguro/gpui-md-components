# gpui-headless

## 役割

特定のデザインシステムに依存しない、見た目を持たない UI の操作基盤。
入力、状態遷移、フォーカス管理、アクセシビリティ情報を担う

## crate 固有の規約

- `gpui` 以外に依存を持たない

## 実装方針

- `Styled`,`InteractiveElement`など`gpui`標準の機能で見た目を設定できるようにする
  - このクレートでは見た目の定義をせず、より上位のレイヤー(アプリケーションなど)に委ねる

## アクセシビリティ

- コンポーネントにはクリックやキーボード操作などのアクセシビリティ機能を実装する
  - コンポーネントは WAI-ARIA Authoring Practices Guide (APG)に準拠させる
  - アクセシビリティ関連機能はテストを実装し、自動で検証可能にする
  - アクセシビリティ要件の判断には [a11y スキル](../../.agents/skills/a11y/SKILL.md) の一次資料を使う
- 操作可能な要素には安定した ID を持たせる
- 操作の状態と、支援技術に伝える役割・状態・アクションを一致させる
