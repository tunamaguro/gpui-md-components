# md3-components

## 役割

GPUI 向けに MD3 の見た目を持つ UI コンポーネントを提供する。
操作基盤・テーマ・アイコンを組み合わせ、利用者向けの部品として公開する

## crate 固有の規約

- 操作・状態遷移・フォーカス管理・アクセシビリティ情報は `gpui-headless` に集約し、この crate は MD3 の見た目を担当する
  - ただし`gpui-headless`の依存をできる限り外部に公開しない
- 色・寸法・書体・形状・モーションは `md3-theme` が提供するトークンと変換を使い、同じ意味の値や変換処理を部品ごとに重複させない
- コンポーネントは対応する Cargo feature でモジュール宣言と再公開を囲み、その feature を無効にした構成でもビルドできるようにする
- `gpui_platform` は利用者向けの再公開に用途を限定し、部品の描画や操作をプラットフォームの起動処理に結び付けない
- 文字倍率・密度・外観・モーション低減の設定を尊重し、利用者の設定を部品固有の固定値で打ち消さない
- 仕様とトークンの移植は [MD3 移植スキル](../../.agents/skills/material-design-3-port/SKILL.md)、アクセシビリティ要件の判断は [a11y スキル](../../.agents/skills/a11y/SKILL.md) に従う
- 各コンポーネントはテーマの上書きに対応する
  - 個別に`md3_theme::SharedTheme`を受け取れるようにする
