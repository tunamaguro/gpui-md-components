# md3-icons

## 役割

必要な Material Symbols の SVG を埋め込み、アイコン名から参照できる形で提供する。
アイコン資産の管理を担う

## crate 固有の規約

- 外部 crate やワークスペース内の他の crate に依存しない
- アイコンの描画・配色・サイズ調整やアクセシブルな名前の付与は利用側の責務とする
- `assets/` と `src/generated.rs` は `cargo xtask gen-icons` で生成し、手で編集しない
- 取得元・リビジョン・バリアントは [assets/SOURCE.md](assets/SOURCE.md) に合わせる。取得条件を変える場合は出典も更新する
- SVG は取得元の内容を無加工で保持し、著作権・ライセンスの情報を保つ
- 資産の追加・削除は、公開するアイコン名・一覧・埋め込みの対応と揃える
- 埋め込み資産の配置を変える場合は、[Nix のソース集合](../../nix/build.nix) に含まれることを確認する
