# md3-theme

## 役割

配色とデザイントークンを利用者の設定に応じて解決し、GPUI で使うテーマを提供する。
GPUI 型への変換、アプリ全体でのテーマ共有、OS の外観への追従を担う

## crate 固有の規約

- 配色アルゴリズムは `md3-color`、既定のデザイントークンは `md3-tokens` を使う。部品の描画や操作状態は持たない
- 設定の既定値と解決処理を一元化する。テーマの再構築や外観の変更で、利用者の上書き設定を失わないようにする
- OS の外観に従う設定と利用者の明示指定を区別し、OS の通知で明示指定を上書きしない
- 論理単位・密度・文字倍率・ウィンドウのスケールを区別し、同じ補正を重複して適用しない
- 書体・形状・色・モーションの上書きはテーマの設定として扱い、個別の部品に設定処理を分散させない
- 色を上書きできることを前提に、コントラストの検査を維持する
