# md3-tokens

## 役割

MD3 の色ロール・書体・形状・寸法・モーションなどを、デザイントークンとして提供する。
共通のトークンとコンポーネント固有の値を保持する

## crate 固有の規約

- GPUI に依存しない。色の参照には `md3-color` の色ロールを使う
- トークン値は一次資料から取得し、出典と参照コミットを残す。取得と転記は [MD3 移植スキル](../../.agents/skills/material-design-3-port/SKILL.md) に従う
- 色・書体・形状の参照関係を保ち、意味を持つトークンを解決済みの描画値に置き換えない
- 寸法は dp / sp などの論理単位で保持する。GPUI 型への変換やテーマ・画面条件に応じた解決は持ち込まない
- コンポーネントごとに異なる値を、数値が似ていることだけを理由に共通化しない
